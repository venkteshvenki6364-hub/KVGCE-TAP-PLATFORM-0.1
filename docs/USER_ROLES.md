# KVGCE TAP — User Roles & Permissions

## 1. Student Role (`student`)
- **Permissions**: View personal dashboard, edit profile, take aptitude/technical/coding assessments, log activities/certifications, view AI career recommendations.
- **Default Credentials**: `student@kvgce.edu.in` / `Password123!`

## 2. Faculty Role (`faculty`)
- **Permissions**: View department student directory, verify/reject submitted student activities, publish subject assessments, provide student feedback.
- **Default Credentials**: `faculty@kvgce.edu.in` / `Password123!`

## 3. Admin Role (`admin`)
- **Permissions**: Full platform access. Manage student and faculty accounts, create users, activate/deactivate accounts, view global analytics, configure departments.
- **Default Credentials**: `admin@kvgce.edu.in` / `Password123!`
