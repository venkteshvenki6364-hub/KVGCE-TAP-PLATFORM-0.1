# KVGCE TAP — Database Seed Data

This directory contains pre-configured JSON seed data files for local development and initial database setup.

## Seed Data Files
- `seed/students.json`: Student profiles.
- `seed/faculty.json`: Faculty profiles.
- `seed/subjects.json`: Course subjects & credits.
- `seed/marks.json`: Academic marks & internal assessments.
- `seed/assessments.json`: Aptitude & technical quiz assessments.
- `seed/activities.json`: Extracurricular activities & certifications.

## How to Execute Seed Data
Run the database seed script:
```powershell
python backend/seed.py
```
